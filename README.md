# Cloud Nurture Solutions

Web application project for cloud-focused solution presentation and iteration.

## Purpose

This repository hosts the application code and UI for experimenting with features and messaging related to cloud service offerings.

## Expected Experience

- Run locally for UI and workflow iteration
- Validate page flows and component behavior
- Deploy previews for feedback and refinement

## Getting Started

```bash
npm install
npm run dev
```

## Notes

Built with a modern front-end stack (Vite + React + TypeScript + Tailwind).
